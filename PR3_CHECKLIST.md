# Соответствие SmartSpace Monitor требованиям ПР3

Основание: «ПР3_Python_ООП.pdf», разделы 5.2, 5.4–5.6, 7.2–7.4.
Предметная область — мониторинг помещений. Room/User/Booking в методичке
являются сквозным примером; в SmartSpace используются свои сущности.

## Контрольные проверки

- Автоматизированные тесты: 115 сценариев, включая параметризованные случаи.
- Проверка оформления: `python -m flake8 .`.
- Дополнительно: совместимость с имеющимися JSON и старым state.json,
  сохранение и повторная загрузка в отдельной временной папке, запуск
  из другой папки, неизменность исходных файлов данных.
- Среда проверки: Python 3.12.14; pytest 9.1.1; flake8 7.4.1.
- Проект рассчитан на Python 3.10+; проверки здесь выполнены на 3.12.

## Критерии 7.3 и материалы вне репозитория

Критерии 2–7, 9–12 подтверждаются исходниками, тестами, документацией
и локальным коммитом PR3. Понимание принципов ООП (критерий 8) необходимо
продемонстрировать лично: пояснения и сценарий находятся в DEFENSE.md.
Критерий 1 — выполнение Яндекс Практикума — подтверждается в самом курсе.
Упоминание курса в README не является доказательством его прохождения.

После push нужно подготовить личный отчёт по 7.4: название работы,
ФИО и группа, выполненные темы, доработка проекта, ссылка на Git-репозиторий
и результат. Объём — 1–2 страницы без титульной информации.
